# Security Policy

## Supported versions

Only the latest release of Nysera receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Instead, report it privately through GitHub:
**Security → Report a vulnerability** on this repository
(GitHub private vulnerability reporting).

Include:
- what the issue is and where it lives (file, command, version)
- steps to reproduce
- the impact you expect

You'll get a reply within a few days. Once a fix ships, we'll credit you
in the release notes unless you'd rather stay anonymous.

## Keep your keys safe

- **Never** paste an API key (OpenRouter or any other provider) into an issue,
  pull request, discussion or screenshot.
- Nysera stores keys only on your machine. If you think a key leaked,
  revoke it in your provider dashboard right away and create a new one.
